# Homelab 建设手册

个人 Homelab 的建设记录与操作手册。目标是**任何一步都能照着重做**，而不是"当时好像是这么弄的"。

每一份文档都按 **是什么 → 为什么这么选 → 选错会怎样** 的结构写，并附上实际踩过的坑。

---

## 阅读顺序

按实际操作顺序编排，建议顺序阅读：

| # | 文档 | 内容 | 什么时候看 |
|---|---|---|---|
| **01** | [Proxmox VE 安装全流程](docs/01-proxmox-install.md) | ISO 下载校验 → 启动盘制作 → BIOS 设置 → 安装向导 → 换源 → 验收 | 装机之前 |
| **02** | [节点初始化与网络规划](docs/02-node-bootstrap.md) | 网段选型 → 地址分配方案 → 路由器配置 → 各类设备的固定 IP 方式 | 装机之前定方案，装完做配置 |
| **03** | [Proxmox VE 核心概念](docs/03-proxmox-concepts.md) | VM vs LXC → 存储分层 → 网桥模型 → 虚拟机硬件模型 → 术语速查 | **建虚拟机之前必读** |

## 硬件清单

### 旧节点 `pve-old`（常开）

| 部件 | 型号 | 备注 |
|---|---|---|
| CPU | Intel i7-12700F | 12C/20T（8P+4E），**F 后缀无核显** |
| 主板 | 华硕 TUF GAMING B660M-PLUS D4 | BIOS 1402 (2022-04)，4 DIMM 槽 |
| 内存 | DDR4-3200 32GB | 实测满频 3200MHz |
| 系统盘 | 铠侠 RC20 1TB NVMe | **无 DRAM 缓存**（影响文件系统选型） |
| 显卡 | 耕升 GTX 1050 Ti 4GB | Maxwell，带 UEFI GOP |
| 网卡 | 板载 Realtek 2.5G | Proxmox 不支持 Wi-Fi，必须走有线 |

### 常开终端

| 设备 | 用途 |
|---|---|
| Mac mini | 管理终端 + **救援通道**（不承担网络转发角色，宿主机故障时仍可上网排查） |

## 环境速查

### 网络

```
网段        192.168.5.0/24
网关        192.168.5.1        中兴光猫
DHCP 池     192.168.5.100–199  租约 24 小时
```

| IP | 主机名 | 说明 |
|---|---|---|
| `.1` | router | 中兴光猫 |
| `.10` | pve-old | 旧节点 Proxmox 宿主机 |
| `.11` | pve-x99 | 新节点（规划中） |
| `.12` | macmini | Mac mini |
| `.20 – .39` | — | 旧节点上的虚拟机与容器 |
| `.40 – .59` | — | 新节点上的虚拟机与容器 |
| `.240 – .250` | — | k8s LoadBalancer 预留 |

完整分配表见 [02 · 节点初始化与网络规划](docs/02-node-bootstrap.md#2-地址分配方案)。

### 常用入口

| 服务 | 地址 |
|---|---|
| Proxmox Web | `https://192.168.5.10:8006`（用户 `root`，Realm 选 Linux PAM） |
| SSH | `ssh root@192.168.5.10` |

## 文档约定

- **图一律用 Mermaid**，源码内嵌在 Markdown 里，写完用 `mmdc` 渲染校验通过才算完成
- **每个配置项说明"为什么"**，而不只是"填什么"
- **踩过的坑单独列表**，标注现象、根因、解决方法
- 命令块可直接复制执行，**不可逆的操作单独警示**

### 渲染校验

```bash
# 安装 mermaid-cli
npm i -g @mermaid-js/mermaid-cli

# 校验某个文档里的图
mmdc -i diagram.mmd -o /tmp/out.svg
```
